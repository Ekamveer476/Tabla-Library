KHalsa School Tabla Library — Shared version

1) In Supabase, open SQL Editor -> New query.
2) Open SUPABASE-SETUP.sql, copy ALL of it, paste into the SQL Editor, and press Run.
3) Copy the contents of this folder into your local GitHub Desktop Tabla-Library folder.
4) In GitHub Desktop: Commit to main -> Push origin.
5) Wait for GitHub Pages to deploy, then refresh your public site.

After this, papers, Homework, taals, and Practice Music are shared for everyone.
Anyone with the public website can edit for now.
